## 📚 Sobre o Projeto

Projeto desenvolvido para a disciplina de **Ciência de Dados e Aprendizagem de Máquina** da **Universidade Braz Cubas**, pela turma **Segunda Noite N1**.

O projeto tem como tema a **Qualidade do Ar Inadequada**, utilizando técnicas de Ciência de Dados e Aprendizagem de Máquina para analisar dados ambientais e, posteriormente, desenvolver um modelo preditivo.

Atualmente, o projeto encontra-se na etapa de **Coleta de Dados**, utilizando dados históricos obtidos por meio de APIs públicas.

---

## 🎯 Objetivo

O objetivo do projeto é utilizar dados históricos de **qualidade do ar** e **condições meteorológicas** para posteriormente identificar e analisar fatores relacionados à ocorrência de condições inadequadas de qualidade do ar.

As fontes de dados utilizadas inicialmente são:

- **Open-Meteo Air Quality API** — dados relacionados à qualidade do ar;
- **Open-Meteo Historical Weather API** — dados meteorológicos históricos.
